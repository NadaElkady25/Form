# Local Storage Sign-Up Form

A simple web page that collects user info (name, ID, phone, email, address) and saves it in the browser using **Local Storage**.  
Saved records appear in a table and can be deleted.

### How to use
1. Open **index.html**
2. Fill the form → **Sign Up**
3. Data stays saved until deleted
4. View saved data in browser:
   Inspect → Application → Local Storage
